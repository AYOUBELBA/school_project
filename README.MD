## 🎯 Overview
FleetManager is a comprehensive fleet management solution that helps transportation companies track their vehicles, manage drivers, plan trips, monitor fuel consumption, and maintain their fleet.

## ✨ Features
- Multi-tenant SaaS
- Fleet Management
- Real-Time GPS Tracking
- Maintenance & Incidents
- Fuel Management
- User Management
- Reports & Analytics
- Mobile App
- Security

## 🛠 Tech Stack
- Backend: PHP 8+
- Database: PostgreSQL
- Frontend: HTML, TailwindCSS, JS
- Mobile: React Native (Expo)

## 🚀 Quick Start
